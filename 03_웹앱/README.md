# Re_Born AI Studio

1회차 수업용 실습 내비게이션 웹앱입니다.

## 열기

`index.html` 파일을 브라우저로 열면 됩니다. 서버 없이 동작합니다.

## 수정할 링크

`script.js` 상단의 `LINKS` 값을 실제 수업 링크로 바꾸면 됩니다.

- `drive`: Google Drive 제출 폴더
- `padlet`: Padlet 작업실
- `worksheet`: 워크시트 파일 경로 또는 공유 링크

## 현재 포함 기능

- 1회차 단계별 안내
- 프롬프트 복사 버튼
- 도구 바로가기
- Padlet 게시 형식
- 수업 체크리스트

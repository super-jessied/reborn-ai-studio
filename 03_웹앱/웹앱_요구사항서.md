# Re_Born AI Studio 웹앱 요구사항서

## 목적

1회차 수업에서 수강생이 PPT와 인쇄 워크시트를 보며 길을 잃지 않도록 돕는 실습 내비게이션 웹앱이다. 웹앱은 강의 내용을 대체하지 않고, 단계별 안내, 프롬프트 복사, 도구 바로가기, 제출·공유 경로 안내를 담당한다.

## 1차 구현 범위

| 구분 | 포함 | 제외 |
|---|---|---|
| 화면 | 홈, 1회차 실습, 프롬프트 카드, 도구 바로가기, 제출·공유 | 2~5회차 상세 화면 |
| 기능 | 프롬프트 복사, 체크리스트, 외부 링크 열기, Padlet 게시 형식 확인 | 로그인, 자체 업로드, 댓글, 진도 저장 |
| 자료 | 1회차 워크시트 흐름, 주제 찾기/핵심문장/5컷 프롬프트 | 영상 파일 업로드, AI API 직접 연동 |

## 수업 흐름

| 단계 | 웹앱 화면 문구 | 작업 시간 | 연결 자료 |
|---|---|---:|---|
| Step 0 | 작업 원칙 | 5분 | 기술보다 나의 시선이 먼저 |
| Step 1 | 나를 이해 | 12분 | 경험·관심·활용 질문 |
| Step 2 | 톤앤무드 | 8분 | 색, 소품/장소, 빛/분위기, 피할 것 |
| Step 3 | 기준표 | 5분 | 대표 비주얼 키워드 3개 |
| Step 4 | 영상 기획 | 20분 | 공통미션 주제, 핵심문장 |
| Step 5 | 5컷 구성 | 20분 | 스토리보드 |
| Step 6 | 공유 | 10분 | Padlet 게시, Drive 저장 |

## 수강생 기준 UI 원칙

- 글씨는 크게, 버튼은 명확하게 배치한다.
- 한 화면에 너무 많은 설명을 넣지 않는다.
- 긴 프롬프트는 직접 입력하지 않고 복사 버튼으로 제공한다.
- Padlet과 Drive는 새 창으로 열리게 한다.
- 첫 수업에서는 “멋진 이미지 완성”보다 “내가 원하는 방향을 말할 수 있게 되는 것”을 목표로 안내한다.

## 향후 확장

2회차 이후에는 같은 구조로 이미지/영상 생성, 음악/나레이션, 편집, 상영회 화면을 추가한다. 1차 버전에서는 2~5회차 메뉴를 준비 중 상태로만 둔다.

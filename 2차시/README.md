# Re_Born AI Studio 2차시 웹앱

## 용도

`군포_ReBorn_AI활용_2차시_퍼스널비주얼카드_이미지맞춤삽입완성본.pptx`를 기준으로 만든 수강생용 실습 내비게이션 웹앱입니다.

## 포함 내용

- 오늘의 목표와 최종 결과물
- 3시간 수업 진행 순서와 단계별 소요 시간
- 핵심 슬라이드 뷰어
- 워크시트 진행 안내
- ChatGPT/Gemini에 붙여넣을 프롬프트 복사 카드
- Google Drive, Padlet 공유 링크
- 다음 차시 준비 체크리스트

## 사용 방법

1. `index.html` 파일을 브라우저로 엽니다.
2. 수업 중에는 상단 바로가기와 프롬프트 복사 버튼을 사용합니다.
3. Drive와 Padlet 링크가 바뀌면 `index.html`의 링크 주소만 교체합니다.

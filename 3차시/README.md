# Re_Born AI Studio 3차시 웹앱

## 용도

`군포_ReBorn_AI활용_3차시_통합강의안.pptx`를 기준으로 만든 수강생용 실습 내비게이션 웹앱입니다.

## 포함 내용

- 3시간 수업 흐름과 오늘의 결과물
- 원본 강의안에서 5·18페이지를 제외한 30장 슬라이드 뷰어
- 8컷 이야기 구성표와 복사형 프롬프트
- 장면 이미지 일관성 프롬프트
- Suno 음악 스타일·가사 프롬프트
- Flow/Seedance 움직임 프롬프트와 예시 영상
- Google Drive·Padlet 링크
- 4차시 준비 체크리스트
- 통합 강의안 다운로드

- `assets/videos`에는 수업용 짧은 예시 영상이 들어 있습니다.
